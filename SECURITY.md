# Security policy

Do not report security vulnerabilities in public issues or pull requests.

Please use GitHub's private vulnerability reporting for
[sagltd/aisc](https://github.com/sagltd/aisc/security/advisories/new). Include
the affected version, impact, and a minimal reproduction where possible. Do
not include live credentials or private user data in a report.

The maintainers will acknowledge reports as soon as they can. No response-time
or remediation-time guarantee is currently offered.
